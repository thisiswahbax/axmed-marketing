# Video projects
One Remotion project per film: `video/<asset-id>-<slug>/` (e.g. `A1.1-hero-film`).
Start with the `axmed-video-brief` skill. Product/proof films use the `axmed-product-video` plugin template.
Renders (`out/`, *.mp4) are git-ignored — store finals in the shared drive and link them in the asset plan.
