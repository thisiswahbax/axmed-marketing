# Axmed logo
Mark extracted from the `axmed-product-video` plugin (`AxmedMark` in ui.tsx), which follows axmed.com.

| File | Use |
|---|---|
| `axmed-logo.svg` / `axmed-logo-white.svg` | **Official lockup** (mark + wordmark) from the marketplace app (`axmed-sina/web/public/images/logo.svg`). Use this by default |
| `axmed-brand-logo.png`, `axmed-icon-rgb.png` | Official raster logo and app icon |
| `sina-ray.svg` | Sina, Axmed's agent (the Ink Ray from `SinaAvatar`). Use only next to Sina features |
|---|---|
| `axmed-mark.svg` | Indigo + cyan, on light backgrounds |
| `axmed-mark-white.svg` | White + cyan, on indigo/photos |
| `axmed-mark-mono-*.svg` | One-colour, for patterns, watermarks, embossing |
| `mark-paths.json` | Raw paths for code (patterns, Remotion) |

Clear space: ≥ ½ mark width on all sides. Min size: 24 px tall.
