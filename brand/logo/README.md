# Axmed logo
Mark extracted from the `axmed-product-video` plugin (`AxmedMark` in ui.tsx), which follows axmed.com.

| File | Use |
|---|---|
| `axmed-mark.svg` | Indigo + cyan, on light backgrounds |
| `axmed-mark-white.svg` | White + cyan, on indigo/photos |
| `axmed-mark-mono-*.svg` | One-colour, for patterns, watermarks, embossing |
| `mark-paths.json` | Raw paths for code (patterns, Remotion) |

Lockup = mark + "Axmed" set in Instrument Sans 700, mark height ≈ 1.4× cap height, gap = ½ mark width.
