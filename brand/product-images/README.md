# Product images

Product scenes (15 Nov 2026 redesign): one tint per module (lavender list and demand, ice quotes, sage quality,
blush delivery), the product card rising from the bottom edge with its last rows fading out, and one callout.
Rendered at 2x from the How it works section of `site/index.html`: edit the HTML there, then run
`node scripts/render-product-images.mjs` (needs `npm install` and `npx playwright install chromium` once).
`overview.jpg` shows all eight. Interfaces are illustrative; label them as such when used.
